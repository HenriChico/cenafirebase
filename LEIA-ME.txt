ENTRELINHAS — BLOG COM FIREBASE
================================

Ficheiros:
- index.html: estrutura da página
- style.css: design responsivo
- script.js: autenticação e operações Firestore
- firestore.rules: regras de segurança da base de dados

1. CRIAR O PROJETO FIREBASE
- Abre https://console.firebase.google.com/
- Cria um projeto.
- Adiciona uma aplicação Web (ícone </>).
- Copia a configuração do Firebase apresentada.

2. CONFIGURAR O FIREBASE NO SITE
- Abre script.js.
- Substitui os valores do objeto firebaseConfig pelos valores reais da tua aplicação.
- Não publiques o ficheiro com os valores de exemplo.

3. ATIVAR O LOGIN
- Na consola Firebase, abre Authentication > Get started.
- Em Sign-in method, ativa Email/Password.

4. CRIAR A BASE DE DADOS
- Abre Firestore Database > Create database.
- Cria a base de dados.
- Vai ao separador Rules e cola o conteúdo de firestore.rules.
- Publica as regras.

5. EXECUTAR O SITE
Não abras simplesmente o index.html com duplo clique, porque o JavaScript usa módulos.
Na pasta do projeto, abre o terminal e executa:

  py -m http.server 8000

Depois abre no navegador:
  http://localhost:8000

Também podes usar a extensão Live Server do Visual Studio Code.

6. PUBLICAR ONLINE
Podes alojar o site com Firebase Hosting. Instala a Firebase CLI e segue:
  npm install -g firebase-tools
  firebase login
  firebase init hosting
  firebase deploy

Durante a configuração do Hosting, escolhe a pasta do projeto como public directory
(ou uma pasta public onde coloques os três ficheiros) e configura como aplicação
de página única apenas se precisares de routing adicional.

NOTAS
- O login e o registo usam Firebase Authentication com email e palavra-passe.
- Os artigos são guardados na coleção "posts" do Cloud Firestore.
- Qualquer pessoa pode ler os artigos.
- Apenas utilizadores autenticados podem publicar.
- Cada utilizador só pode apagar os próprios artigos.
- Esta versão não inclui recuperação de palavra-passe, comentários, imagens ou edição de artigos.
